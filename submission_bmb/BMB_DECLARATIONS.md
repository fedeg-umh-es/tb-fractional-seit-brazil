## 6. Data Availability
The empirical epidemiological data analyzed in this study comprise aggregate monthly tuberculosis notification records for Brazil (2001–2022, $N = 264$), which are publicly accessible via the Brazilian National System for Notifiable Diseases (SINAN / DATASUS, https://datasus.saude.gov.br/). The curated monthly time series and data processing scripts are hosted in the project GitHub repository, which will be made public prior to submission [FEDEG_INPUT_REQUIRED: insert repository URL once public].
